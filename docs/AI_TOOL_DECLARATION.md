# AI-tool declaration

This repository's implementation and documentation were developed with assistance from GitHub Copilot, an AI coding assistant in VS Code. AI assistance was used for code exploration, drafting implementation changes, and documentation. The human project team remains responsible for reviewing, testing, and submitting the work.

The running prototype does not currently have a configured production AI model provider. AI features exposed by the application must not be described as live model-backed execution unless a provider is configured and the end-to-end request, authorization, provenance, and failure paths have been tested.

This declaration describes development assistance; it does not claim that project research artifacts were generated by a model. Contributors should disclose AI use on each artifact through the project workflow when that feature is available.
